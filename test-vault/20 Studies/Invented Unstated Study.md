# Invented study with no recorded scope

**Invented, and deliberately incomplete.** It has an IRB reference and no
`governance.identifiers`.

The point of the fixture is that this does **not** read as "no identifiers
approved", and it does not read as "anything goes" either. An identifier on a
form linked here is reported as *uncheckable*, because nobody wrote the scope
down. Silence is not approval — the same rule C3 applies to a script with no
recorded run, and C2 to a definition nobody dated.
