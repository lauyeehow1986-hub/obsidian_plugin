# Invented app with no code

**Invented, and deliberately unfinished.** There is no ```js app``` block, so
there is nothing to run.

It is the fixture that proves the board says *why* an app cannot run rather
than showing a Run button that does nothing when pressed. A note someone
started and never finished is an ordinary thing to find in a vault, and it
should read as unfinished rather than as broken.
