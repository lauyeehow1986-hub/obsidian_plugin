# Invented case reference number

**Invented.** Flagged as an identifier with **no `justification`**, deliberately,
so the catalogue board's governance finding fires against a fixture rather than
only in a unit test.

The finding is not "this is wrong". It is that nothing in the vault records why
an identifier is held — which is the same question a REDCap form export has to
answer against the study's approved scope, and it is cheaper to answer here.
